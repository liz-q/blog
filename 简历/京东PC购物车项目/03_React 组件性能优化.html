React 组件性能优化

李征2025/8/15大约 2 分钟

React 性能优化最重要的一部分是组件的写法上，如果组件写不好就会导致过多的无用刷新。

开发组件要遵循以下原则：

  • 单一封闭原则
  • 把变的与不变的分离
  • 高内聚低耦合
  • 抽象 props 和 state 状态
  • 利用性能优化 api（memo，useMemo，useCallback） 减少组件不必要的渲染次数

示例一

VendorName 组件使用 memo 包装

import {memo, ReactNode} from 'react'

interface VendorNameProps {
  shopId: number
  shopName: string
  children?: ReactNode
}

const VendorName = ({shopId, shopName, children}: VendorNameProps) => {
  return (
    <>
      <a href={`//mall.jd.com/index-${shopId}.html`} target="_blank">
        {children}
        {shopName}
      </a>
    </>
  )
}

export default memo(VendorName)

使用 VendorName

 <VendorName shopId={vendor.shopId} shopName={vendor.shopName}>
  {vendorHead.map((item, index) => (
    <VendorFlag key={index} flagTag={getVendorEnumByTag(item.u)} />
  ))}
</VendorName>

假如 shopId 和 shopName 属性值不变，那么 VendorName 的刷新就决定于 children 是否改变，memo 是浅比较。但是上面的写法是用 map，也就是每次都会返回一个新数组，那么 children 一定会变，从而 VendorName 一定会刷新，那么 VendorName 的 memo 就没用了，反而会影响性能，毕竟多了一层闭包嘛！

那么这个问题怎么解决呢？

首先 children 每次都是一个新数组，它一定会变，所以 VendorName 一定会刷新，那索性就不要 VendorName 了，可以改成下面这种结构，然后 VendorFlag 用 memo 包一下

<a href={`//mall.jd.com/index-${vendor.shopId}.html`} target="_blank">
  {vendorHead.map((item, index) => (
    <VendorFlag key={index} flagTag={getVendorEnumByTag(item.u)} />
  ))}
  {vendor.shopName}
</a>

VendorFlag

import { memo } from 'react'
import { ProductVendorEnum } from '@app/config/productEnum'
import classnames from 'classnames'
import styles from './index.module.scss'

export interface VendorFlagProps {
  flagTag?: ProductVendorEnum
  name?: string
}

const VendorFlag = ({ flagTag, name }: VendorFlagProps) => {
  return flagTag ? (
    <i
      className={classnames(styles['vendor-icon'], styles[flagTag])}
      title={name ? name : ''}
    />
  ) : null
}

export default memo(VendorFlag)

示例二

useCallback 缓存函数

const handleTitleTextClick = useCallback(() => {
  reportClick('shopClick', {
    shopid: vendor.shopId,
    shop_name: vendor.shopName,
  })
}, [vendor.shopId, vendor.shopName])

useEffect(() => {
  console.log('测试 handleTitleTextClick 变化了没')
}, [handleTitleTextClick])

结果首次会打印，后续只要 vendor.shopId, vendor.shopName 的值不变函数就不变。
