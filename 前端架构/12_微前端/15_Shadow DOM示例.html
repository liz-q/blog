Shadow DOM 完整示例

下面是一个完整的 Shadow DOM 示例，展示如何创建封装的自定义元素，包含样式隔离、插槽内容分发和事件处理。

1. 基础 Shadow DOM 示例

<!DOCTYPE html>
<html>
<head>
  <title>Shadow DOM 完整示例</title>
  <style>
    /* 主文档样式 - 不会影响 Shadow DOM */
    p {
      color: blue;
      font-weight: bold;
    }
  </style>
</head>
<body>
  <p>主文档中的段落（蓝色粗体）</p>
  
  <!-- 自定义元素 -->
  <shadow-box></shadow-box>

  <script>
    class ShadowBox extends HTMLElement {
      constructor() {
        super();
        
        // 1. 创建 Shadow Root（开放模式）
        const shadow = this.attachShadow({ mode: 'open' });
        
        // 2. 定义内部 HTML 结构
        shadow.innerHTML = `
          <style>
            /* 只作用于 Shadow DOM 内部的样式 */
            p {
              color: red;
              border: 1px solid gray;
              padding: 10px;
            }
            
            .container {
              background-color: #f0f0f0;
              padding: 15px;
              margin: 10px 0;
            }
          </style>
          
          <div class="container">
            <p>Shadow DOM 内部的段落（红色边框）</p>
            <slot></slot> <!-- 内容插槽 -->
          </div>
        `;
      }
    }

    // 3. 注册自定义元素
    customElements.define('shadow-box', ShadowBox);
  </script>
  
  <!-- 使用自定义元素并传入内容 -->
  <shadow-box>
    <p>通过插槽传入的内容（保持主文档样式）</p>
  </shadow-box>
</body>
</html>

2. 带命名插槽的复杂示例

<!DOCTYPE html>
<html>
<head>
  <title>Shadow DOM 插槽示例</title>
</head>
<body>
  <user-card>
    <span slot="username">张三</span>
    <span slot="email">zhangsan@example.com</span>
    <div>未分配插槽的内容不会显示</div>
  </user-card>

  <script>
    class UserCard extends HTMLElement {
      constructor() {
        super();
        
        const shadow = this.attachShadow({ mode: 'open' });
        
        shadow.innerHTML = `
          <style>
            :host {
              display: block;
              width: 300px;
              border: 1px solid #ccc;
              border-radius: 5px;
              padding: 15px;
              font-family: Arial, sans-serif;
              box-shadow: 0 2px 5px rgba(0,0,0,0.1);
            }
            
            h2 {
              color: #333;
              margin-top: 0;
              border-bottom: 1px solid #eee;
              padding-bottom: 10px;
            }
            
            p {
              color: #666;
            }
            
            ::slotted([slot="username"]) {
              font-weight: bold;
              color: #0066cc;
            }
          </style>
          
          <div class="user-card">
            <h2><slot name="username">未命名用户</slot></h2>
            <p>邮箱: <slot name="email">暂无</slot></p>
            <p>注册时间: <slot name="regdate">未知</slot></p>
          </div>
        `;
      }
    }

    customElements.define('user-card', UserCard);
  </script>
</body>
</html>

3. 动态 Shadow DOM 示例（带交互）

<!DOCTYPE html>
<html>
<head>
  <title>交互式 Shadow DOM</title>
</head>
<body>
  <counter-widget start="5"></counter-widget>

  <script>
    class CounterWidget extends HTMLElement {
      static get observedAttributes() {
        return ['start'];
      }

      constructor() {
        super();
        this.attachShadow({ mode: 'open' });
        this.render();
        
        this.increment = this.increment.bind(this);
        this.decrement = this.decrement.bind(this);
      }

      connectedCallback() {
        this.shadowRoot.querySelector('#inc').addEventListener('click', this.increment);
        this.shadowRoot.querySelector('#dec').addEventListener('click', this.decrement);
      }

      disconnectedCallback() {
        this.shadowRoot.querySelector('#inc').removeEventListener('click', this.increment);
        this.shadowRoot.querySelector('#dec').removeEventListener('click', this.decrement);
      }

      attributeChangedCallback(name, oldValue, newValue) {
        if (name === 'start' && oldValue !== newValue) {
          this.render();
        }
      }

      get count() {
        return parseInt(this.getAttribute('start')) || 0;
      }

      set count(value) {
        this.setAttribute('start', value);
      }

      increment() {
        this.count = this.count + 1;
        this.render();
      }

      decrement() {
        this.count = this.count - 1;
        this.render();
      }

      render() {
        this.shadowRoot.innerHTML = `
          <style>
            :host {
              display: inline-block;
              border: 1px solid #ddd;
              padding: 10px;
              border-radius: 4px;
              font-family: sans-serif;
            }
            
            .counter {
              font-size: 24px;
              margin: 0 15px;
              min-width: 50px;
              display: inline-block;
              text-align: center;
            }
            
            button {
              background: #4CAF50;
              border: none;
              color: white;
              padding: 8px 16px;
              text-align: center;
              text-decoration: none;
              display: inline-block;
              font-size: 16px;
              margin: 4px 2px;
              cursor: pointer;
              border-radius: 4px;
            }
            
            button:disabled {
              background: #cccccc;
              cursor: not-allowed;
            }
          </style>
          
          <button id="dec" ${this.count <= 0 ? 'disabled' : ''}>-</button>
          <span class="counter">${this.count}</span>
          <button id="inc">+</button>
        `;
      }
    }

    customElements.define('counter-widget', CounterWidget);
  </script>
</body>
</html>

4. Shadow DOM 样式穿透示例

<!DOCTYPE html>
<html>
<head>
  <title>Shadow DOM 样式控制</title>
  <style>
    /* 从外部影响 Shadow DOM 的样式 */
    styled-card::part(header) {
      background-color: #4CAF50;
      color: white;
    }
    
    styled-card::part(content) {
      font-size: 18px;
      line-height: 1.6;
    }
  </style>
</head>
<body>
  <styled-card></styled-card>

  <script>
    class StyledCard extends HTMLElement {
      constructor() {
        super();
        const shadow = this.attachShadow({ mode: 'open' });
        shadow.innerHTML = `
          <style>
            .header {
              padding: 15px;
              background-color: #f1f1f1;
              border-radius: 5px 5px 0 0;
            }
            
            .content {
              padding: 15px;
              border: 1px solid #ddd;
              border-top: none;
              border-radius: 0 0 5px 5px;
            }
          </style>
          
          <div part="header" class="header">
            <slot name="header">默认标题</slot>
          </div>
          <div part="content" class="content">
            <slot name="content">默认内容</slot>
          </div>
        `;
      }
    }

    customElements.define('styled-card', StyledCard);
    
    // 动态添加内容
    document.querySelector('styled-card').innerHTML = `
      <h2 slot="header">自定义标题</h2>
      <p slot="content">这是通过插槽传入的内容，外部样式可以控制带有 part 属性的元素</p>
    `;
  </script>
</body>
</html>

关键点总结

  1. Shadow DOM 创建：

    const shadow = element.attachShadow({ mode: 'open' });

  2. 样式隔离：

    • Shadow DOM 内部的样式不会影响外部
    • 外部样式默认不会影响 Shadow DOM

  3. 内容分发：

    • 使用 <slot> 元素定义内容插入点
    • 命名插槽：<slot name="xxx">

  4. 样式控制：

    • :host 选择器用于设置宿主元素样式
    • ::slotted() 选择器用于设置插槽内容样式
    • ::part() 允许外部有限地控制 Shadow DOM 样式

  5. 生命周期：

    • connectedCallback - 元素插入 DOM 时调用
    • disconnectedCallback - 元素从 DOM 移除时调用
    • attributeChangedCallback - 监听属性变化

这些示例展示了 Shadow DOM 的核心功能，包括封装、样式隔离、内容分发和交互功能，可以基于这些模式构建更复杂的自定义元素。
